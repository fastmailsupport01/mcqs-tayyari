Grade Calculator — Purana + 2026 Naya System

Sirf percentage dalen, system chunen, grade foran dekhen.

Note zaroori: Naya system SSC-I/HSSC-I par First Annual 2026 se aur SSC-II/HSSC-II par 2027 se laagu ho raha hai, is liye apni class ke mutabiq system chunen taake confuse na hon.

Purana system: 80%+ A+, 70–79% A, 60–69% B, 50–59% C, 40–49% D, 33–39% E, 33% se kam Fail (per subject pass 33%).
2026 naya system: 96–100% A++, 91–95% A+, 86–90% A, 81–85% B++, 76–80% B+, 71–75% B, 61–70% C+, 51–60% C, 40–50% D, 40% se kam U (Ungraded/Fail).
